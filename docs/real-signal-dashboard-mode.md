# Real Signal Dashboard Mode

## Difference between demo and operational signals

Demo signals are portfolio scaffolding. They help show the layout, filtering, and review flow without implying live operational use.

Real signals are manually curated, source-backed strategic observations. They are the version Profile A should treat as the operational path.

## Why real signals are manually curated

Manual curation protects the dashboard from weak sources, duplicate hype, and false certainty.

Each signal should be reviewed for source quality, relevance, and strategic meaning before it is treated as operationally useful.

## Why Profile A prioritizes signal quality over quantity

Profile A is designed to support judgment, not volume.

A smaller set of high-quality signals is more useful than a larger set of noisy items because it supports:

- faster review
- clearer prioritization
- better source discipline
- stronger decision support

## Current operational limits

This mode is still intentionally lightweight.

- No backend
- No scraping
- No authentication
- No automatic ingestion
- No charts yet

The dashboard is operational in presentation, but still manual in data handling.
