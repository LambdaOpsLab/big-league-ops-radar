# Real Use v1

## What changed from demo to operational use

The demo version proved the portfolio layout and information hierarchy.

Real Use v1 adds a manually reviewed real-signal set, source traceability, decision trails, and pattern framing so the dashboard can support a credible operational workflow.

## Strategic patterns that appeared

Across the curated set, several patterns became clear:

- AI-first government programs are being productized through secure and managed deployments
- Sovereign compute is linking cloud, chips, and local control
- Operational governance now includes evidence, review state, and decision history
- Infrastructure commitments are getting larger and more explicit
- Human-in-the-loop review is still required before promotion or project creation

## Why manual curation still matters

Manual curation keeps the dashboard useful and trustworthy.

It ensures each signal is selected for a reason, linked to a real source, and reviewed before being promoted. That reduces hype and keeps the system focused on judgment rather than noise.

## Current operational limitations

- No scraping
- No backend
- No automatic ingestion
- No automation engine
- No real-time claim of completeness

## Safe roadmap

Future work should only expand into intake or automation after governance is stable.

That means:

- establishing a reliable review queue
- adding persistence only when needed
- introducing ingestion only with source controls
- adding automation only after promotion rules are stable

The safe path is to preserve the review model before increasing throughput.
