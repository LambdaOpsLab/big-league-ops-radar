# Strategic Pattern Memory

## Difference between signals and patterns

A signal is a reviewed observation about a specific event, announcement, or source-backed development.

A pattern is the repeated shape that appears after reviewing multiple signals over time.

Signals are specific. Patterns are cumulative.

## Why repeated observation matters

One reviewed signal can be interesting. Several reviewed signals pointing in the same direction are more valuable because they reveal recurrence, not just novelty.

That repeated observation helps the radar identify durable themes like AI-first government adoption, sovereign infrastructure, and human-in-the-loop governance.

## Why strategic memory matters

Strategic memory lets the radar keep track of what has been seen, reviewed, and reinforced.

Without pattern memory, the dashboard can still show individual signals, but it will miss the larger operating story that emerges across time.

## Current limits of manual patterning

- No AI-generated pattern engine
- No embeddings or vector database
- No automatic clustering
- No scraping
- No backend

Patterning is intentionally manual so the portfolio reflects judgment and review discipline rather than automated inference.

## Future roadmap

Future work should expand pattern memory only after the review process is stable.

That means:

- more curated signal history
- clearer pattern promotion rules
- optional persistence for saved pattern notes
- stronger review cadence

The roadmap should remain conservative. The goal is to improve strategic memory, not to claim automated intelligence.
